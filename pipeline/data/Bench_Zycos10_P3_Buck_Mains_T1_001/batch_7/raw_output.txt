For a 250V to 3.3V conversion, a flyback or SEPIC topology would be more appropriate. The flyback topology is better suited for this application as it provides isolation and can handle the wide input voltage range more efficiently.

I'll design a flyback converter with the following parameters:

- Output voltage: 3.3V
- Power: 200W
- Switching frequency: 100kHz
- Duty cycle: 13.2m/250 = 0.0528

* 250V to 3.3V Flyback, 200W
Vin in 0 250
M1 in gate 0 0 NMOS W=1 L=1
L1 0 sw 100u
C1 sw out 100u
D1 out 0 DIODE
Rload out 0 0.0545
Vgate gate 0 PULSE(0 12 0 1n 1n 5.28u 10u)
.model NMOS NMOS(Vto=1 Kp=2 Lambda=0)
.model DIODE D
.tran 10n 10m
.save V(*) I(*)
.end
