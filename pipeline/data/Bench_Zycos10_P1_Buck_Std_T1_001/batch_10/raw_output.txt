 CANDIDATE 1

 For example:
- Change Vin to 24V

- Replace DIODE with 1N5408

* 24V to 12V Buck, 30W
Vin in 0 24
M1 in gate sw 0 NMOS W=1 L=1
D1 0 sw DIODE
L1 sw out 100u
C1 out 0 470u
Rload out 0 4.8
Vgate gate 0 PULSE(0 12 0 1n 1n 5.8u 10u)
.model NMOS NMOS(Vto=1 Kp=2 Lambda=0)
.model DIODE D
.tran 10n 1m
.save V(*) I(*)
.end
