* 220V to 12V Step-Down Converter
Vin in 0 220
M1 in gate sw 0 NMOS W=1 L=1
D1 0 sw DIODE
L1 sw out 47u
C1 out 0 220u
Rload out 0 1.8
Vgate gate 0 PULSE(0 12 0 1n 1n 2.77u 10u)
.model NMOS NMOS(Vto=1 Kp=2 Lambda=0)
.model DIODE D
.tran 1u 10m
.end
