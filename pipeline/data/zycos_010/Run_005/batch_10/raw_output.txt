 CANDIDATE 6
============================================================

 5V from 200V is a 40:1 step-down, requiring a very low Rload (0.125Ω for 200W). A 2-phase interleaved buck is overkill for 200W, and the simulation shows it's not working.

Use a flyback or SEPIC instead for 200V to 5V. For a flyback, D=5/(5+200)=0.0245, t_on=245n for T=10u. L1=200u, M1 is low-side switch.

* 200V to 5V flyback, 200W
Vin in 0 200
L1 in sw 200u
M1 sw gate 0 0 NMOS W=1 L=1
D1 sw out DIODE
C1 out 0 100u
Rload out 0 0.125
Rbleed sw 0 1Meg
Vgate gate 0 PULSE(0 12 0 1n 1n 245n 10u)
.model NMOS NMOS(Vto=1 Kp=2 Lambda=0)
.model DIODE D
.tran 10n 1m
.save V(*) I(*)
.end
