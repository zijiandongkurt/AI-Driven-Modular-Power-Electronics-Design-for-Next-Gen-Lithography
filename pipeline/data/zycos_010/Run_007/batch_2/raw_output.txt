 For a boost, you need a higher duty cycle (D=1-Vin/Vout) to get a higher output voltage. Your D=5.8u/10u=0.58, which is too low for Vin=20V to Vout=400V. Need D=1-20/400=0.95, so t_on=9.5u, T=10u. Increase L1 from 100u to 220u for lower ripple. Also, Rload=V^2/P=160, not 320. Fix Vgate timing and component values.

 CANDIDATE 2
============================================================

 Do not repeat the same netlist.
* 20V to 400V boost, 500W
Vin in 0 20
L1 in sw 100u
M1 sw gate 0 0 NMOS W=1 L=1
D1 sw out DIODE
C1 out 0 220u
Rload out 0 320
Vgate gate 0 PULSE(0 12 0 1n 1n 5.8u 10u)
.model NMOS NMOS(Vto=1 Kp=2 Lambda=0)
.model DIODE D
.tran 10n 1m
.save V(*) I(*)
.end
