 CANDIDATE 1

 For boost, try increasing inductor value and adjusting switch timing. Let's try 20V to 400V boost with larger L1 and longer t_on. D=1-20/400=0.95, T=10u, t_on=9.5u.

* 20V to 400V boost, 500W
Vin in 0 20
L1 in sw 100u
M1 sw gate 0 0 NMOS W=1 L=1
D1 sw out DIODE
C1 out 0 220u
Rload out 0 320
Vgate gate 0 PULSE(0 12 0 1n 1n 9.5u 10u)
.model NMOS NMOS(Vto=1 Kp=2 Lambda=0)
.model DIODE D
.tran 10n 1m
.save V(*) I(*)
.end
